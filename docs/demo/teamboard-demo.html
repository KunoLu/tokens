# Developer Group Usage

先选择一个团队

Teamboard 一次展示一个团队。登录用户默认选中自己所属的团队；未登录访客可自行选择任意公开团队。

本页改动：整体布局与 Leaderboard 一致，差异只有两处——新增 Team 单选与 Group 多选两个筛选项；列中不含 Team（已按单团队过滤），但保留 Group 列。 试试选择 Neon Ravens 再勾选多个分组，观察成员列表的递进筛选。
团队可见范围（PRD §13 D-2 已确认）： teams.visibility 取 public / private，建团时由 admin 显式选择，admin 与 subadmin 事后可改， 数据库默认 private。筛选器列出「公开团队 ∪ 你自己所属的团队」—— Atlas Guild 是私有团队且你不是成员，因此根本不出现在下拉里；直接请求它的 id 会返回 404（用 404 而非 403，避免被用来枚举团队是否存在）。

注意：Leaderboard 的 Team / Group 列是你明确要求的，团队名对所有访客可见，private 也不例外。 可见性控制的是「能否按团队聚合浏览完整成员名单」，不是「团队名是否公开」。

危险操作

解散团队

把所有成员（含你自己）移出团队。团队进入 disbanded 状态，不可撤销。解散后你仍保留删除权。

删除团队

仅当团队已解散且成员数为 0 时可用。当前成员 8 人，因此按钮禁用。

你的权限（admin）

  • 改名 / 改头像 / 邀请 / 移除成员
  • 指派 subadmin（上限 2，已用 1）
  • 分组的增改删与解散
  • 解散团队（subadmin 不可）
  • 删除团队（subadmin 不可）

subadmin 差异

除解散与删除团队外，权限与 admin 相同，包含对分组的全部操作。

两段式生命周期：解散与删除是两步。解散清空成员，删除要求成员为 0。 因为解散会把 admin 也移出，删除权由 teams.created_by 承载——否则解散后将无人有权删除。

Install the CLI

The CLI scans the AI coding clients already installed on your machine, totals the usage locally, and submits only the totals.

macOS
brew install tokens tokens login — sign in with email brew services start tokens — submit automatically
Linux
curl -fsSL https://tokens.ci/install.sh | sh tokens login — sign in with email tokens serve — submit automatically
Windows
bunx tokens-cli@latest login — sign in with email bunx tokens-cli@latest submit

新建分组

分组隶属于当前团队，成员必须先是团队成员。同一团队内名称唯一。

解散团队？

这会把 8 位成员（含你自己）全部移出团队，且不可撤销。解散后团队进入 disbanded 状态，你作为创建者仍可执行删除。

无法退出团队

你是 Neon Ravens 的 admin。未解散的团队必须恰有一个 admin，因此你需要先把 admin 移交给其他成员，或直接解散团队。

退出分组 frontend？

你仍然留在 Neon Ravens 团队，只是不再属于任何分组。榜单的 Group 列会变为空。
